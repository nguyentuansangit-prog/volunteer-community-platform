# Project Rules

## Definition of Ready

Một Issue được chuyển sang Ready khi:

- Có User Story hoặc mục tiêu rõ ràng.
- Có Acceptance Criteria có thể kiểm tra.
- Đã xác định vai trò và quyền truy cập.
- Đã xác định dữ liệu hoặc API liên quan.
- Có người phụ trách.
- Có Priority.
- Có Estimate.
- Phạm vi đủ nhỏ để hoàn thành trong 1-3 ngày.

## Definition of Done

Một Issue được chuyển sang Done khi:

- Đáp ứng toàn bộ Acceptance Criteria.
- Được ít nhất một thành viên khác review.
- Đã kiểm tra Happy Path.
- Đã kiểm tra Edge Case.
- Đã kiểm tra quyền truy cập.
- `npm run lint` thành công.
- `npm run build` thành công.
- Preview Deployment hoạt động.
- Không để lộ dữ liệu bí mật.
- Test case và tài liệu đã được cập nhật nếu cần.
